# Sky right now

`sky-now.js` exposes synchronous `mountSkyNow(host,{lat,lng,clouds,state})`, returning `{destroy,element,refresh}`. Pass a stable mutable state object to retain target, search, direction and user location across parent redraws; call destroy when the detail closes. Hidden/disconnected views stop work; detached mounts clear their timer/listeners. Refresh is once per minute while visible, not a remote data poll.

The module imports local Astronomy Engine 2.1.19 and fetches local `sky-catalog.json` and `sky-object-facts.json` once. Lazy-import it only when Sky Tonight opens. Engine remains MIT-licensed with its source header. d3-celestial data is BSD3-licensed; `vendor/CELESTIAL-DATA-LICENSE.txt` preserves the notice. Details/credits are in sky-now-sources.html. No network weather feed is needed for geometric sky positions; supplied current cloud rows are used only near the source location and time.

J2000 catalog star/line coordinates are rotated with `Rotation_EQJ_HOR`, accounting for precession/nutation, and refraction applied through `HorizonFromVector`. Planet/Sun/Moon positions use topocentric `Equator` of-date with aberration then `Horizon`. Stars are fixed catalog positions (no proper motion); accuracy is appropriate for naked-eye finding, not astrometry. Stars through magnitude4.5 are plotted; 88 constellation figures occupy89 records because Serpens has separate sourced Caput/Cauda geometries. Below-horizon stars/planets are never plotted but can be searched. Object detail rise/set uses AstronomyEngine over next48hours; no crossing is not a visibility guarantee.

Facing chart is clockwise azimuth left-to-right and altitude bottom-to-top. Whole-sky chart is a looking-up chart with east left when north is top; circumference horizon, center zenith. Declination/RA endpoint wraps are normalized. Manual direction is always usable. Phone compass is optional, permission-on-click, requires flat holding and is explicitly approximate/magnetic-capable. No camera permission is used. The app does not claim automatic augmented-reality alignment or calibrated true north from the sensor. Geolocation is on-click only and remains in the in-memory chart state. Switching to map center cancels pending location callbacks.

Static catalog, source definitions and formula/library are not daily refresh work. Update only for a relevant release, correction or confirmed defect. Time/location positions are computed locally each minute. `node scripts/sky-now-test.mjs` verifies catalog consistency, projections, reference positions, location/time changes and valid input; run it for changes to this feature, not as a broad daily audit.
