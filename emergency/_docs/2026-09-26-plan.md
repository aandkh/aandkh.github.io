# Chill (family emergency app mock) Implementation Plan

> Executed inline in the session that wrote it (the owner asked for no
> further check-ins; no subagents). Code lives in the files named below;
> this plan fixes the boundaries, interfaces, tests and verification.

**Goal:** Build the mock described in `2026-09-26-design.md` at
`/emergency/` on www.andrewhanes.com.

**Architecture:** Static page, vanilla ES modules, no build step. A pure
`logic.js` owns every rule (who sees whom, timers, incidents, check-ins,
Peace of Mind, disguise text expiry) and is unit-tested in a browser test
page. `store.js` persists state and runs the demo clock; `sim.js` plays the
pretend family and phones; UI modules render from state.

**Tech Stack:** HTML, CSS, JavaScript modules. Google Fonts (Bricolage
Grotesque). Python `http.server` for local preview. Pillow only in
the icon generator.

**Spec:** `emergency/_docs/2026-09-26-design.md`

## Global Constraints

- No dependencies, no build, no external scripts. Fonts via Google Fonts only.
- Phone first: correct at 360 to 430 px wide; wider screens show a centered
  430 px column. Safe-area insets respected (`viewport-fit=cover`).
- Hold threshold: 500 ms for SOS, silent alert and iMessage bubbles; 400 ms
  for Google Messages bubbles. Cancel if the finger moves more than 10 px.
- App name "Chill". Dark theme only; tokens in the spec's "Look (dark)"
  section are the palette. One font: Bricolage Grotesque.
- Family colors: Mom `#A85A14`, Dad `#2F6FDF`, Ava `#C2367C`, Leo `#1B7A50`.
- UI copy: plain words, no em dashes.
- Never dial 911, never request real personal data, never claim a pretend
  result is real (Peace of Mind is labeled "Demo: simulated results").
- Every state change the family would care about writes a log entry.

## Local preview

`.claude/launch.json` config `emergency` runs
`python -m http.server 8765 --bind 127.0.0.1` in the repo root; open
`http://127.0.0.1:8765/emergency/` and tests at
`http://127.0.0.1:8765/emergency/_tests/`.

### Task 2: logic.js, visibility, sharing, incidents, log (TDD)

**Files:** create `js/logic.js`, `_tests/logic.test.js`.

**Produces:**
- `createDemoState(now): State` with members `mom, dad, ava, leo`
  (`name, color, initial, pos {lat,lng}, pin: null, share {kind:'off'}`,
  `nightly {on, time:'23:00', lastCheckIn:null}`, `checkIn:null`,
  `device:'ok'`), `incidents: []`, `log: []`, `viewer:'ava'`, `disguise`,
  `peace {lastRunAt:null}`, `sound:true`. Dad starts sharing until 9:40 PM
  demo time.
- `canSee(state, viewerId, targetId, now): Reason|null` where Reason is
  `'self'|'sharing'|'presser'|'presser-sees-all'`.
- `visibleTo(state, viewerId, now): string[]`, `whoCanSee(state, targetId,
  now): {id, reason}[]` (excludes the target itself).
- `setShare(state, id, kind, now, ms?)` kinds `off|timed|on|emergency`;
  `activeIncident(state): Incident|null`;
  `startIncident(state, presserId, kind, now): Incident` kinds
  `button|silent|missed`; `respond(state, incidentId, memberId, what, now,
  etaMin?)` what `seen|onway`; `endIncident(state, incidentId, byId, reason,
  now)` reasons `safe|accident|resolved`; `tick(state, now): Event[]`;
  `addLog(state, now, text)`.

Tests (each an `eq`/`ok`):
- [ ] Calm: nobody sees anybody except self and Dad (sharing): Ava sees
  `['ava','dad']`; Dad sees `['dad']`.
- [ ] Timed share expires in `tick` at its end time; afterwards Ava sees
  only herself; an event `share-ended` for dad is returned; a log line.
- [ ] Ava's emergency: everyone sees Ava; Ava sees all four; Mom does not
  see Leo; `whoCanSee(ava)` lists mom, dad, leo with reason `presser`.
- [ ] Leo shares `emergency` during Ava's incident: Mom sees Leo; ending the
  incident turns Leo's share `off` and Mom no longer sees Leo.
- [ ] Only one active incident: a second `startIncident` while one is
  active returns the existing incident unchanged.
- [ ] `respond` records `seen`, `onway` with ETA; responses start `unseen`.
- [ ] `endIncident` sets `endedAt`, `endedBy`, `endReason`, logs, and
  visibility returns to calm.

### Task 3: logic.js, check-ins, PIN, Peace of Mind, disguise texts (TDD)

**Files:** modify `js/logic.js`, `_tests/logic.test.js`.

**Produces:** `setCheckIn(state, id, dueAt, note, now)`,
`clearCheckIn(state, id)`, `checkIn(state, id, now)`,
`nextNightlyDue(member, now): number`, `setPin(state, id, pin)`,
`pinMatches(state, id, pin): boolean`, `peaceReadyIn(state, now): ms`,
`startPeace(state, now): boolean`, `peaceResult(device): {phone: 'on' |
'no-answer', gps: 'located' | 'off' | null, alertsOff: boolean}`, `addSentText(state, text,
now)`, `pruneTexts(state, now): number` (removed count).

Tests:
- [ ] One-time check-in: `tick` emits `checkin-reminder` once at due - 5 min,
  `checkin-lastcall` once at due, and at due + 2 min starts a `missed`
  incident for that member carrying the note; `checkIn` before due clears it.
- [ ] Nightly 23:00: at 21:00 the next due is today 23:00; after a check-in
  at 21:30 the next due is tomorrow 23:00; a check-in at 19:00 (more than 3 h
  before) does not count; at 22:55 reminder; missed flow as above.
- [ ] PIN: `pinMatches` false before a PIN is set; true for the set PIN;
  only 4 digits accepted by `setPin` (returns false otherwise).
- [ ] Peace of Mind: ready immediately; after `startPeace` not ready for
  30 000 ms, ready at 30 000 ms; `startPeace` during cooldown returns false;
  `peaceResult`: `ok` gives phone on + GPS located; `offline` gives phone
  no-answer + GPS null; `locationOff` gives phone on + GPS off; `alertsOff`
  gives phone on + GPS located + alertsOff true.
- [ ] Texts: `pruneTexts` removes texts older than 24 h exactly and keeps
  newer ones.
